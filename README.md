# 大冶市低空经济综合运行服务平台 · 大屏可视化演示

基于《大冶低空平台需求功能清单 V1.0》设计实现的低空经济指挥中心大屏演示页。纯前端静态产物，**双击 HTML 即可离线运行**，无需构建、无需联网。

> **在线预览**：https://liugang12334-cloud.github.io/daye-lowaltitude-dashboard/
> （设计稿 1920×1080，建议 F11 全屏；根路径会自动跳转到源码版大屏）

## 目录结构

```
.
├── lowaltitude-dashboard/          # 源码版大屏（推荐查看/二次开发）
│   ├── index.html                  # 页面骨架（五区布局）
│   ├── styles.css                  # 暗色科技风样式与组件
│   ├── app.js                      # 地图图层、图表、场景/视图切换、语音助手
│   └── assets/
│       ├── echarts.min.js          # 本地 ECharts 5.5.1
│       ├── daye.js                 # 大冶市行政区划边界（内联 GeoJSON）
│       └── data.js                 # 演示数据层（KPI / 机队 / 航线 / 告警 / 场景）
├── 大屏演示/
│   ├── 大冶低空经济总态势大屏.html   # 单文件版本（内联全部资源，便于投屏拷贝）
│   └── 大冶低空经济总态势大屏设计方案说明.docx
└── 大冶低空平台需求功能清单V1.0.xlsx  # 需求来源（MVP 86 项 + 全量 215 项）
```

## 快速开始

```bash
# 方式一：直接打开
open lowaltitude-dashboard/index.html

# 方式二：本地起服务（推荐，避免个别浏览器 file:// 限制）
cd lowaltitude-dashboard && python3 -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080
```

## 页面构成

- **顶部**：数据链路 / 市级平台 / MQTT 状态灯，天气与秒级时钟
- **控制条**：一主三专视图切换、演示徽标、自动轮播、需求映射、暂停刷新、四套场景
- **KPI 指标带**：飞行架次、在飞目标、设备在线率、安全运行天数、订单量、营收
- **GIS 一张图**：市域底图 + 空域网格（禁飞/限飞/适飞）+ 9 条航线 + 10 个起降场 + 12–21 架实时目标与尾迹；6 个图层开关、3 个书签、滚轮缩放拖拽、点击目标查看参数卡
- **左栏**：机队四态环形图、空域态势与审批、实时告警
- **右栏**：24h 架次趋势（含预测虚线段）、任务场景构成、起降场单量 TOP5
- **底部**：告警 / 电子运单 / 平台对接三段滚动
- **语音助手"小冶"**：地图底部居中悬浮，问数回填 + KPI 高亮 + 控屏（放大城区）

## 视图与场景

| 类型 | 取值 | 说明 |
|---|---|---|
| 视图 | `overview` / `device` / `logistics` / `safety` | 一主三专，切换只换两侧面板与地图专属图层，KPI 带保持不变 |
| 场景 | `normal` / `peak` / `emergency` / `medical` | 常态运行 / 早高峰配送 / 应急处置 / 医疗急救，联动 KPI、机队、告警、地图事件 |

URL 参数便于汇报直开：

```
index.html?view=logistics&scene=peak&intro=0   # 直达物流屏+早高峰，关闭开场播报
index.html?modal=1                             # 直接展开「需求→模块」映射表
```

## 技术说明

- 纯原生 JS + ECharts 5，无框架、无构建链，所有依赖本地化
- 严格 1920×1080 设计稿，按 `transform: scale()` 等比适配任意分辨率大屏
- 地图使用 ECharts `geo` 组件；`assets/data.js` 按"统一指标服务"口径组织，接真实接口时替换该文件即可，`app.js` 无需改动

## 地图合规声明

当前底图使用大冶市行政区划边界数据（DataV GeoAtlas），**仅用于内部方案演示与评审**，不作为对外发布的地理信息服务。正式上线需替换为天地图 / 腾讯地图等具备审图号的官方服务，届时将 `assets/daye.js` 换成官方行政区图层即可，其余图层逻辑不变。

## 需求映射

页面内置「需求映射」弹层，将工单 §7「可视化大屏」的 24 条要点（KPI 口径、目标层、刷新机制、语音问数等）逐条映射到对应展示模块，便于评审时逐项对照。
